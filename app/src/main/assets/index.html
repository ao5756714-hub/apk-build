APK'larım
Başlamak için sol üstteki ☰ menüsünden GitHub token'ını kaydet.
Henüz APK oluşturmadın.
Sağ üstteki “+ Yeni” ile başla.
Henüz dosya seçilmedi.
Uygulama bu siteyi açar; internet gerekir.
Sayfalar resme çevrilip alt alta gösterilir (en fazla 100 sayfa); bağlantılar çalışmaz.
Ayarlar
Token oluştur (izinler hazır) Açıksa APK indirme bağlantısı giriş istemeden çalışır; yüklediğin dosyalar GitHub'da herkese görünür. Silme özelliği için token'da delete_repo izni gerekir.
